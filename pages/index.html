Before you start

Use a current Chrome or Chromium browser with WebAssembly JSPI. The first visit may reload once to enable browser isolation.

Android startup can take several minutes. Keep this tab visible. Software graphics can still freeze or respond slowly; this is an experiment.

The goal is to make trying Android apps as easy as opening a link. APK upload is not available yet.
