# Android workspace design

The page is an Android workspace. On desktop, a compact left panel contains
the introduction, image details, session controls and network settings. The
right panel contains status, the Android display, real boot progress and errors.
The display is visible in the first viewport. On narrow screens the panels
stack and the Android surface keeps its aspect ratio.

Use Manrope at regular and bold weights, a warm pale green page, dark green
text, a forest green primary action and an ink green display surround. The
Android content supplies the visual interest. Avoid fake Android screenshots,
decorative charts and controls for unsupported choices.

Keep experimental status visible. Use native buttons, selects, details and
textareas with keyboard focus rings. Preserve descriptive labels, live status,
alert errors, disabled session settings and reduced motion preferences.
Do not call a configured WISP endpoint connected until an Android request
succeeds. Share links carry configuration, never running Android state.
